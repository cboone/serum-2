## [Unreleased]

### Added

- `tools/serumfile.py` for reading, verifying, listing, diffing and writing Serum 2 presets and curves, including a `rowcurves` subcommand that names, for each matrix row, the matching curve file in a given folder.
- `tools/make_sweep.py` for generating the Dirichlet Sweep wavetables, and the generated tables in `serum/Tables/`.
- A Serum 2 file-format reference in `docs/SERUM-FILE-FORMAT.md`.
- A synthetic example preset and curves for the scrut tests, generated by `tests/scrut/fixtures/make_fixtures.py`, under CC0.
