## [Unreleased]

### Added

- `tools/serumfile.py` for reading, verifying, listing, diffing and writing Serum 2 presets and curves, including a `rowcurves` subcommand that names, for each matrix row, the matching curve file in a folder. The `CURVE_DIR` argument is required; there is no default folder.
- A `meta` subcommand in `tools/serumfile.py` that prints a preset's header or sets its name, author, comment, description and URL in place, refusing any file whose body would not re-encode byte for byte.
- `patch` and `sortmatrix` subcommands in `tools/serumfile.py`: apply a JSON merge patch to a preset, and put its matrix rows in a canonical, destination-first order.
- `tools/make_sweep.py` for generating the Dirichlet Sweep wavetables, and the generated tables in `serum/Tables/`.
- A Serum 2 file-format reference in `docs/SERUM-FILE-FORMAT.md`.
- A synthetic example preset and curves for the scrut tests, generated by `tests/scrut/fixtures/make_fixtures.py`, under CC0.
- A contributing guide, code of conduct, security policy and pull request template.
- README instructions for decoding presets and curves in `git diff` in your own repository.
