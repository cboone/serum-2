# serum-2

## Scope

Open-source (MIT) command-line tools for Serum 2 files: the preset and curve container reader and writer, and the Dirichlet Sweep wavetable generator. This is a Tier 1 Catamount Audio repository. It holds tools, the file-format reference, generated wavetables, and CC0 example and fixture files only. Presets designed as products or showcases, and private measurement or design tooling, do not belong here, and this repository never links to private repositories.

Read `docs/SERUM-FILE-FORMAT.md` for file structures.

## Rules

- Keep the ownership statement and the Xfer Records not-affiliated disclaimer in the README.
- Code is MIT. Wavetables in `serum/Tables/` and fixtures in `tests/scrut/fixtures/serum/` are CC0 (`LICENSE-ASSETS`). Any new example file must be CC0 and either generated by a script in this repository or plainly non-creative.
- Never add presets, curves or wavetables copied from Serum's factory content or from third-party packs.
- State whether a claim about the format was confirmed against files saved by Serum, stated in a manual, or inferred. Do not present inferred structure as established.
- `serum/Tables/` holds generated artifacts. Regenerate them with `tools/make_sweep.py serum/Tables`; never edit them by hand.
- Test fixtures are generated. Change `tests/scrut/fixtures/make_fixtures.py` and rerun it (`PYTHONPATH=tools uv run --script tests/scrut/fixtures/make_fixtures.py tests/scrut/fixtures/serum`) instead of editing fixture files.

## Development

The Python tools are standalone scripts with pinned PEP 723 dependencies and `tools/*.py.lock` files. Do not add a package manifest. When changing a dependency, update its script block and lockfile with `uv lock --script`, then run `make check`. Scripts importing `serumfile` need `PYTHONPATH=tools` and their own matching PEP 723 pins.

| Command          | Purpose                                                |
| ---------------- | ------------------------------------------------------ |
| `make check`     | Run code, text, format, and scrut checks               |
| `make text-fix`  | Format and lint Markdown                               |
| `make git-setup` | Configure decoded preset and curve diffs in this clone |

Verify every generated file by decoding it or comparing checksums.
