# serum-2

Command-line tools for reading, writing, inspecting and diffing Serum 2 presets, curves and wavetables, built on a reverse-engineered description of the file format.

## Contents

- [`tools/serumfile.py`](tools/serumfile.py): read, verify, dump, diff and write Serum 2 presets (`.SerumPreset`) and curves (`.XferShape`), list a preset's modulation matrix (`matrix`), name the curve file loaded in each matrix row (`rowcurves`), and list a curve's points (`curve`).
- [`tools/make_sweep.py`](tools/make_sweep.py): generate the Dirichlet Sweep wavetables.
- [`docs/SERUM-FILE-FORMAT.md`](docs/SERUM-FILE-FORMAT.md): the `.SerumPreset` and `.XferShape` container, the curve and preset layouts, and the wavetable marker.
- [`serum/Tables/`](serum/Tables): the Dirichlet Sweep wavetables, as generated by `make_sweep.py`.
- [`tests/scrut/fixtures/`](tests/scrut/fixtures): a synthetic example preset and curves, and [`make_fixtures.py`](tests/scrut/fixtures/make_fixtures.py), which generates them.

## Installation

The tools need [uv](https://docs.astral.sh/uv/). Each script declares its own dependencies inline, so there is nothing else to install.

```bash
git clone https://github.com/cboone/serum-2.git
```

## Usage

```bash
tools/serumfile.py verify    PRESET.SerumPreset   # hash and round-trip check
tools/serumfile.py matrix    PRESET.SerumPreset   # readable mod-matrix listing
tools/serumfile.py rowcurves PRESET.SerumPreset CURVE_DIR   # which curve file each row holds
tools/serumfile.py diff      A.SerumPreset B.SerumPreset
tools/serumfile.py curve     CURVE.XferShape
tools/make_sweep.py          OUTDIR
```

To use the wavetables, copy `serum/Tables/*.wav` into the `Tables/User` folder inside Serum's Serum 2 Presets folder.
